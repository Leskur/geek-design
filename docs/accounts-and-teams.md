# 账号与空间

账号与数据按空间隔离，不提供全局管理员绕过空间权限。现有数据目录需随备份一并保留。

## 日常流程

1. `/register` 注册独立账号，用户名 2–50 字符（英文、数字、点、横线、下划线），密码 6–200 字符。用户名忽略大小写且全局唯一。
2. 注册成功即创建 **个人空间**（名称跟随用户名，显示为「用户名的空间」；英文用户名与中文之间空一格，首字大写），并成为该空间拥有者；进入工作台后优先打开最近使用且仍有权限的空间。
3. 可另建 **协作空间**。创建者成为拥有者。一个账号可以拥有或加入多个协作空间。
4. 协作空间拥有者在页面右上角邀请成员，生成邀请链接。当前为链接邀请，不会发送邮件。**个人空间不能邀请成员。**设置、重命名和成员收在右上角的向下箭头里。
5. 受邀者打开 `/invite/:token`，注册或登录后返回同一个邀请页面，主动接受邀请。
6. 加入协作空间后即可查看该空间内全部文件夹与设计，无需再分配项目级权限。文件夹为可选归类：设计可直接放在空间根目录，也可放进文件夹。

## 权限

| 角色 | 权限 |
| --- | --- |
| 个人空间拥有者 | 仅本人；可上传、重命名、移动、删除设计与文件夹；不能邀请、不能删除个人空间、不能改名 |
| 协作空间拥有者 | 邀请/撤销邀请、移除普通成员；可删除任意设计与文件夹；可删除协作空间；可维护字体库 |
| 协作空间成员 | 查看全部文件夹与设计；可上传、新建文件夹；只能删除/重命名/移动自己创建的设计；不能邀请或移除他人 |

拥有者不能被移除。拥有者转让、账号找回和 SSO 尚未实现。文件夹仅作归类，没有单独权限表。

移除协作空间成员时撤销其创建的未使用邀请。被移除后不能凭已使用邀请重新加入；需重新获取新邀请。

## 邀请

- 32 字节随机令牌，数据库仅保存 SHA-256；原始链接只在生成时展示，之后可撤销并重新生成。
- 固定有效期 7 天，单个链接供一人使用，加入角色固定为成员。仅拥有者可生成邀请。
- 已加入空间的账号再次接受同一邀请可安全重试，不会改变角色。
- 已使用、过期、撤销或不存在的链接有明确状态；其他账号不能再次使用已经接受的邀请。
- 邀请链接不会记录到正常请求日志，页面设置 `Referrer-Policy: no-referrer`。请仍只向预期成员分享链接。

## 地址与存储

`/login`、`/register`、`/spaces`、`/spaces/:spaceId`（空间主页，含根目录设计与文件夹）、`/spaces/:spaceId/workspace`（工作台）、`/spaces/:spaceId/members`、`/spaces/:spaceId/fonts`。设计优先使用 `/spaces/:spaceId/designs/:designId`；`/folders/:folderId`、`/folders/:folderId/designs/:designId` 仍可用。页面与画板由查询参数定位。

主要表：`users`、`spaces` / `space_members`、`folders`、`designs`（`space_id` 必填，`folder_id` 可空表示空间根）、`invitations`（挂 `space_id`）、`uploads`（挂 `design_id`）、`space_fonts`。原文件及解析产物仍由对象存储和任务处理层管理。设计只有当前一份稿，覆盖上传会更新同一设计并重新解析，不再保留修订列表。

空间、文件夹、设计及上传记录的对外 ID 即数据库主键：12 位随机字符串（Node.js `randomBytes` → base64url），创建时检查业务表避免冲突。邀请令牌、文件内容哈希以及 Sketch 内部页面/图层 ID 保持原样。备份仍需包含整个 SQLite 与数据目录。

登录、注册、邀请与空间权限均由后端验证。开放部署后当前注册允许任何能访问应用的人创建账号；空间仍隔离。此版本定位可信局域网试用，未提供账号治理、配额和生产级审计。

## 工作台体验

日常入口围绕空间根目录与文件夹。侧边栏顶部用下拉切换空间（个人空间优先，并可新建协作空间），其下是「全部」和「字体库」。侧栏不做重命名 / 删除等管理操作。空间页右上角是「新建」和「邀请」（个人空间没有邀请），再往右是向下箭头。新建可以选择文件夹，或上传一份设计。箭头展开后显示当前空间名称，以及设置、重命名、成员。进入空间主页可见根目录设计与文件夹，点击文件夹进入该文件夹。文件卡片可以直接打开设计，更多菜单提供覆盖上传、复制链接、重命名、移动与删除。上传可在空间根或文件夹内进行；新建文件夹可选。空目录支持拖入 Sketch。上传弹窗可以收起，当前标签页内任务继续；页面刷新仍需重新选择文件续传。界面色彩在 `src/theme.css` 统一。

搜索、网格/列表切换可用于设计文件。最近打开只在当前浏览器保存设计 ID 和时间，按账号隔离，展示时仍由后端空间权限筛选，不会跨设备同步。文件卡片封面优先使用 Sketch 自带的 `previews/preview.png`；没有该文件或加载失败时回退静态占位。图标使用 Lucide React。

直接打开设计链接时，首帧显示查看器加载骨架与处理状态；失败时提供重试和返回工作台，不显示本地文件欢迎首页。

## 删除与快捷操作

空间页与文件夹卡片支持更多操作；设计卡片支持右键及更多菜单。协作空间仅拥有者可删除；个人空间不可删除。文件夹由空间拥有者删除。设计由创建者或空间拥有者删除。删除前展示范围与不可撤销的确认弹窗，后端独立验证权限。删除协作空间级联移除文件夹、设计、上传记录、邀请、字体元数据与成员关系；删除文件夹、设计按相应范围处理，数据库事务保证失败时全部回滚。正在上传、校验或解析的内容会阻止删除，完成后再操作。

原文件、图片对象与解析产物可能被多个设计复用。删除设计、文件夹或空间后会回收已无任何设计引用的对象与解析产物；仍被其他设计引用的内容保留。不做软删除或回收站。旧链接删除后返回不存在或无权访问。

应用显示名称为 GeekDesign，现有仓库、环境变量和本地偏好键保持兼容。页面视图顶部可关闭设计返回文件夹或工作台；单画板视图可返回页面，不另设设计切换器。

## 名称编辑与设计移动

协作空间拥有者可重命名协作空间；个人空间名称跟随用户名，不能单独修改。空间成员可重命名文件夹。设计的创建者或空间拥有者可重命名设计、移动设计。

设计可移动到同一空间的其他文件夹，或移回空间根（`folder_id` 置空），保留设计 ID 与当前文件，无需重新上传。正在上传或解析的设计需完成后再移动。移动后仍按所属空间的访问规则（同一空间内成员可见）。

## 空间字体库

空间页的「字体库」支持搜索、上传、预览、下载和删除字体。仅空间拥有者可维护字体，成员可查看、预览和下载，下载文件使用上传时的文件名。支持 TTF、OTF、WOFF、WOFF2，单个文件不超过 20 MB；自动读取名称、字重、样式，不支持 TTC 字体集合。相同内容重复上传会复用；同一个 PostScript 名称的不同文件需先删除旧版本，避免字体匹配歧义。

空间设计按原稿字体名自动加载所需字体，优先匹配 PostScript 名称，不需要在每个文件夹重复配置。回到设计窗口时会同步字体库，加载完成后更新缺失提示；失败可在字体弹窗重试。

查看器顶栏用警告色字体图标提示当前页面缺失字体，数量只在悬停说明中展示。字体库入口仅在字体弹窗内：拥有者通过文字链接前往上传，普通成员可查看字体库并联系拥有者上传。也可临时从本机加载，该方式不会上传且刷新后失效。本地文件模式只提供临时加载，不关联空间字体库。

远景简化绘制可能使用简化文字排版。字体匹配不保证覆盖所有字符，具体排版仍以原稿和字体文件为准。

字体元数据保存在 SQLite，文件位于 `data/fonts/`，请随整个数据目录一起备份。删除字体后，新打开的设计不再加载该字体；已打开页面刷新后生效。删除元数据不立即清理共用的字体文件。
