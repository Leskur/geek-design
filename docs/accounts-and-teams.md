# 账号与空间

`/register` 注册：用户名 2–50 字符（英文、数字、点、横线、下划线），忽略大小写且全局唯一；密码 6–200 字符。注册后得到个人空间，名称跟随用户名，不能邀请、改名或删除。

可另建协作空间。拥有者用链接邀请成员（有效 7 天、一人一次，不发邮件）。成员能看到该空间全部内容。文件夹只是归类，设计也可以直接放在空间根目录。每个设计只有当前一份稿，覆盖上传即更新。

## 权限

| 角色 | 能做什么 |
| --- | --- |
| 个人空间拥有者 | 上传、改名、移动、删除自己的设计和文件夹 |
| 协作空间拥有者 | 邀请 / 移除成员；删除任意设计与文件夹；删除协作空间；维护字体库 |
| 协作空间成员 | 查看全部；上传、建文件夹；只能改自己创建的设计 |

拥有者不能被移除。删除没有回收站。正在上传或解析时不能删。被多个设计共用的文件，删到没有引用才会清掉。

设计可在同一空间内移动，ID 和当前文件不变。

## 字体库

仅拥有者可上传和删除。支持 TTF、OTF、WOFF、WOFF2，单文件不超过 20 MB，不支持 TTC。成员可查看和下载。设计按字体名自动匹配；也可临时从本机加载（刷新后失效）。本地文件模式只有临时加载。
