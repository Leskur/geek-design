# 开发检查、切图与导出

页面和单画板视图共用右侧面板。选中元素后直接展示信息，不再显示「设计检查」标题、开发 / 资源切换页签或详细属性区块。主要区块展开显示，不常驻显示拖动画布、按需加载等操作说明。

## 按所选类型展示

- 文字：文案优先，随后显示布局、字体排版和 CSS。
- 图片或图片填充：原图资源靠前，随后显示布局和 CSS。
- 容器（分组、组件、画板）：优先显示自身布局、CSS，再提供边缘距离和分组颜色；不合并子元素的字体、文案、图片资源列表或 CSS。
- 切图与导出位于面板后部，避免占据常用属性的首屏。

布局坐标相对父级，宽高为图层原始尺寸，不再切换到画板坐标。容器宽高优先，X / Y 弱化显示。边缘距离直接展示，采用类似浏览器盒模型的四边数字与中间尺寸布局，但表示到父级的实际距离，不推断 CSS margin 或 padding。

## 属性与代码

属性值点击即可复制，文案和 CSS 的复制入口为小图标，悬停显示用途。混合文字可按片段切换，显示该片段的字体属性和 CSS；复制全部时用独立类名区分图层与不同片段，需按项目应用。

CSS 分为「布局」和「样式」两组，文字属性归入样式。透明度、圆角、旋转等统一在 CSS 中体现，默认值不输出；不会仅凭设计稿的图层位置生成 Flex / Grid 或 padding。

普通文字、形状不重复展示「所选颜色」，颜色在字体属性或 CSS 中查看。分组、组件或画板包含多种可提取颜色时，提供「分组颜色」辅助取色，支持 HEX / RGB。提取的是图层样式色，不是图片像素取色。

## 图片资源

资源行左侧是 56px 缩略图，右侧显示图层名称及原图分辨率，例如 `原图 1920 × 1080 px`；不显示内部资源路径。最右侧用小下载图标下载原图，文件以图层名称命名并保留图片类型。

原图下载取得素材本身，不应用图层裁切、圆角、蒙版和缩放。原图分辨率、图层显示尺寸和切图尺寸是三个不同概念。

## 切图

切图预览常驻显示当前所选元素的可见内容，固定使用 PNG 1×，与导出格式、倍率分开。透明区域使用棋盘格；预览按内容比例自适应高度，最高 320px。标题右侧用小字显示裁边后的 1× 像素尺寸。

按实际渲染结果裁掉四周透明留白，保留半透明边缘；完全不可见的选区显示错误，不导出空白图。倍率改变不会重新生成切图预览。

## 导出

「导出 ＋」仅在需要时展开格式、倍率和下载按钮，收起不隐藏切图预览。所有类型使用同一个导出入口；图片另有下载原图的小图标。

支持 PNG、SVG、JPG，常用倍率 1× / 2× / 3×。优先读取原稿首个支持的导出格式和倍率，没有配置时默认 PNG 2×。只有点击下载时才按所选格式与倍率生成文件，文件名为 `<图层名>@<倍率>x.<格式>`。导出设置下方不重复显示尺寸。

PNG / SVG 保留透明区域；JPG 在裁边后铺白底。SVG 保留可支持的矢量形状，但文字按当前浏览器字体转为图像嵌入，不是可编辑矢量文字。调整倍率影响下载文件，不改变固定 1× 切图显示。

导出以选中元素的本地坐标与旋转范围为基础，不包含父级蒙版；超出原始导出范围的内容和阴影可能被裁切。字体缺失、复杂蒙版、混合模式等还原差异会反映在结果中。单次输出限制为每边不超过 16384px、总计不超过 3200 万像素，超出时应降低倍率。

## 字体提示

顶栏仅在当前页面缺少字体时显示警告色 `spell-check-2` 图标，不显示数量；悬停显示数量，点击打开字体弹窗。页面字体按名称去重，并扫描引用组件和共享文字样式，不为此展开整页场景。

- 空间模式：拥有者看到前往字体库上传的文字链接，普通成员看到联系拥有者的说明和查看字体库链接。字体库入口只在弹窗内，不常驻顶栏。
- 本地模式：临时从本机加载，不上传；刷新或关闭页面后失效。
- 空间模式也可临时加载；已匹配但读取失败的字体单独显示加载失败及重试入口，避免误导重复上传。

空间字体库的权限、格式和存储规则见 [账号与空间](accounts-and-teams.md#空间字体库)。
