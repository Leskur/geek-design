# 开发检查、切图与导出

选中元素后右侧直接展示信息。

- 文字：文案、布局、字体、CSS。
- 图片或图片填充：原图、布局、CSS。
- 分组、组件、画板：自身布局和 CSS，以及到父级的边缘距离；不合并子元素的字体、文案或图片。

布局坐标相对父级，宽高是图层原始尺寸。属性值点击复制；文案和 CSS 用小图标复制。CSS 分「布局」和「样式」，默认值不输出，不会凭图层位置生成 Flex / Grid 或 padding。

原图下载是素材本身，不带裁切、圆角、蒙版和缩放。切图预览固定 PNG 1×，按渲染结果裁掉四周透明留白。导出支持 PNG、SVG、JPG，常用 1× / 2× / 3×；没有原稿导出配置时默认 PNG 2×。JPG 铺白底；SVG 里文字会按当前字体转成图。单次输出每边不超过 16384px、总计不超过 3200 万像素。

当前页缺字体时，顶栏出警告图标。空间模式可去字体库上传；本地模式只能临时从本机加载，刷新后失效。
