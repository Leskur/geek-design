# 本地与局域网部署

## 开发

Node.js 24，执行 `npm install`、`npx playwright install chromium --only-shell`、`npm run dev`。前端 5173，后端 5174。账号入口 `http://127.0.0.1:5173/register`，团队入口 `/teams`。用户自行注册账号，密码至少 6 个字符；注册后可以创建团队或接受邀请，无需全局管理员初始化。详见 [账号与团队](./accounts-and-teams.md)。

## 局域网运行

先 `npm run build`。关闭原开发服务，在 PowerShell 设置以下环境变量再运行：

```powershell
$env:SKETCHPEEK_HOST='0.0.0.0'
$env:SKETCHPEEK_PORT='5174'
$env:SKETCHPEEK_PUBLIC_ORIGIN='http://192.168.1.100:5174'
npm start
```

把示例地址换成服务器实际局域网地址；团队浏览器访问该地址。防火墙需要允许所选端口，仅开放给可信局域网。普通 HTTP 不加密登录与文件内容，需要加密时应在受控反向代理前配置 HTTPS，并把 PUBLIC_ORIGIN 改为实际 HTTPS 地址。HTTPS 模式的会话 cookie 只通过 HTTPS 发送。反向代理需要保留原始 Host，关闭请求体缓冲或调大上传限制，不要把 `/api/tus` 改写到其他路径。

默认只监听本机，不会自动修改防火墙或开放公网。此版本已在本机完成端到端验证，尚未验证两台实体电脑访问。

## 数据与备份

默认数据在项目 `data/`，可用 `SKETCHPEEK_DATA_DIR` 指定其他本机绝对目录。包括 SQLite、原始对象、图片、上传会话和解析产物。不要放到网络共享盘。`src/` 是前端，`server/` 是后端，`shared/` 是共同的文档结构；它们独立构建，暂时放在一个仓库。

同一个目录只运行一个服务；`server.lock` 记录当前进程，启动时会检查。不要删除正在运行服务的锁。备份时正常停止服务后，复制整个数据目录；恢复同样替换完整目录。升级前备份，不要只复制 SQLite 主文件。

`.env` 当前不会自动加载。配置通过启动进程的环境变量传入。`SKETCHPEEK_MAX_FILE_SIZE` 是原文件字节上限，默认 1 GiB；单页 JSON 上限 150 MiB，单图片 80 MiB，压缩包总展开上限 2 GiB、条目上限 30,000。

## 上传与记录规则

- 浏览器先逐块计算 SHA-256，仍需要本地读取时间；已有同内容时跳过网络文件传输。
- 同一文档重复内容返回原记录，不新增版本，也不把当前稿倒退到该记录。
- 同项目可以复用已经校验的文件；跨项目需要实际上传并通过服务器校验，不能只提交一个哈希获得访问权。
- 传输可以暂停。刷新后选择同一文件并选原目标文档，可从服务端已接收位置继续。
- 文件传完后由后台处理，关闭浏览器不影响解析。处理失败保留记录，可以重新处理；未通过文件校验的记录需要重传。
- 固定链接需要登录且具有项目查看权限。新稿不会改变旧链接；已就绪记录可以手动设为当前稿。
- 同时提交的多个新稿以创建时的当前稿为基准：较迟完成的任务不会自动覆盖已经改变的当前稿，需要手动确认。

## 当前边界

尚未实现云存储、自动清理废弃上传、空间配额、删除回收站、账号停用/密码找回、操作审计、版本差异和 AI 交付包。失败与中断的上传可能占用空间，应定期检查磁盘。暂不建议开放到公网或用于要求完整账号治理的生产环境。后台任务单进程串行运行，优先处理已传完的文件。

原始 Sketch 没有浏览器下载接口；只提供已授权记录的页面、组件与图片。解析对文档结构有资源限制，查看还原度沿用现有渲染器的兼容边界，不能视为与 Sketch 原生逐像素一致。

团队地址使用 `/projects/:projectId/documents/:documentId/revisions/:revisionId` 定位固定稿件；`?page=…&artboard=…` 定位画板。本地查看入口 `/local`。旧的 `/?team=1` 和 `/?revision=…` 链接仍支持，授权后转换为对应路径。


## 服务端缩略图

首次部署在运行服务的同一系统账号下安装渲染组件：

```sh
npx playwright install chromium --only-shell
```

Linux 可使用 `npx playwright install --with-deps chromium --only-shell` 安装系统依赖，并安装中文字体（例如 Noto CJK）。升级 Playwright 后需重新执行安装。仅服务器需要 Chromium，团队成员浏览器不需要安装。无头渲染页面禁用脚本与外部网络请求，图片直接来自已校验的本地资源。

上传解析完成后，独立预览任务为每个画板生成 PNG，最长边受限于 384px 宽 / 1536px 高。任务不会阻塞稿件进入可查看状态；同一解析产物共享预览，并按渲染版本分目录保存。预览使用服务端字体，缺失字体仍可能导致与设计原稿差异。

启动时补齐已有、仍有稿件引用的解析产物。任务状态存放在 SQLite 的 thumbnail_jobs，图片与索引在 artifacts/<key>/thumbnails/thumb-1/。每张 PNG 完成后原子发布，已完成图片立即可读；重启继续缺失部分。源图片先预缩放并限制缓存，浏览器按 24 张一批回收，渲染器异常时自动重试当前画板一次。失败可由有上传权限的成员在总览重试，不改变设计稿的可查看状态。备份需一并保留这些文件。
