# 本地与局域网部署

除下文的源码运行外，也支持 [Docker Compose 部署](docker.md)。空间数据仍按单实例保存，切换部署方式时需完整迁移数据目录。

## 开发

Node.js 24，执行 `npm install`、`npm run dev`。前端 5173，后端 5174。账号入口 `http://127.0.0.1:5173/register`，空间入口 `/spaces`。用户自行注册账号，密码至少 6 个字符；注册后自动获得个人空间，也可创建协作空间或接受邀请，无需全局管理员初始化。详见 [账号与空间](./accounts-and-teams.md)。

## 局域网运行

先 `npm run build`。关闭原开发服务，在 PowerShell 设置以下环境变量再运行：

```powershell
$env:SKETCHPEEK_HOST='0.0.0.0'
$env:SKETCHPEEK_PORT='5174'
$env:SKETCHPEEK_PUBLIC_ORIGIN='http://192.168.1.100:5174'
npm start
```

把示例地址换成服务器实际局域网地址；局域网浏览器访问该地址。防火墙需要允许所选端口，仅开放给可信局域网。普通 HTTP 不加密登录与文件内容，需要加密时应在受控反向代理前配置 HTTPS，并把 PUBLIC_ORIGIN 改为实际 HTTPS 地址。HTTPS 模式的会话 cookie 只通过 HTTPS 发送。反向代理需要保留原始 Host，关闭请求体缓冲或调大上传限制，不要把 `/api/tus` 改写到其他路径。

默认只监听本机，不会自动修改防火墙或开放公网。此版本已在本机完成端到端验证，尚未验证两台实体电脑访问。

## 数据与备份

默认数据在项目 `data/`，可用 `SKETCHPEEK_DATA_DIR` 指定其他本机绝对目录。包括 SQLite、原始对象、图片、上传会话和解析产物。不要放到网络共享盘。`src/` 是前端，`server/` 是后端，`shared/` 是共用的文档结构、字体规则和渲染模块；应用入口独立构建，放在同一个仓库。模块边界见 [代码结构](architecture.md)。

同一个目录只运行一个服务；`server.lock` 记录当前进程，启动时会检查。不要删除正在运行服务的锁。备份时正常停止服务后，复制整个数据目录；恢复同样替换完整目录。升级前备份，不要只复制 SQLite 主文件。

`.env` 当前不会自动加载。配置通过启动进程的环境变量传入。上传文件和解压 JSON 默认不限制体积；需要上限时再设置 `SKETCHPEEK_MAX_FILE_SIZE`、`SKETCHPEEK_MAX_JSON_SIZE` 为正整数字节数。留空或 `0` 表示不限制。

例如 Linux 启动时：

```bash
SKETCHPEEK_MAX_JSON_SIZE=536870912 npm start
```

超过自行设置的 JSON 上限时，错误会显示具体文件名、解压后大小和当前上限。调整后，已上传且校验通过的失败稿件可通过「重新处理」重试，无需重新上传。

这些值是文件大小限制，不是进程内存预算。JSON 文本、解析对象和中间数据可能占用数倍内存，实际需求随图层结构变化。

## 上传与记录规则

- 浏览器先逐块计算 SHA-256，仍需要本地读取时间；已有同内容时跳过网络文件传输。
- 同一设计重复上传相同内容返回原记录，不重复处理。
- 覆盖上传会更新同一设计并重新解析；同文件夹内可复用已经校验的文件内容。跨文件夹需要实际上传并通过服务器校验，不能只提交一个哈希获得访问权。
- 传输可以暂停。刷新后选择同一文件并选原目标设计，可从服务端已接收位置继续。
- 文件传完后由后台处理，关闭浏览器不影响解析。处理失败保留记录，可以重新处理；未通过文件校验的记录需要重传。
- 设计链接需要登录且具有所属空间的成员权限。设计只有当前一份稿，没有修订历史列表。

## 当前边界

尚未实现云存储、自动清理废弃上传、磁盘配额、删除回收站、账号停用/密码找回、操作审计、版本差异。失败与中断的上传可能占用磁盘，应定期检查。暂不建议开放到公网或用于要求完整账号治理的生产环境。后台任务单进程串行运行，优先处理已传完的文件。

原始 Sketch 没有浏览器下载接口；只提供已授权设计的页面、组件与图片。解析对文档结构有资源限制，查看还原度沿用现有渲染器的兼容边界，不能视为与 Sketch 原生逐像素一致。

设计地址使用 `/folders/:folderId/designs/:designId`；`?page=…&artboard=…` 定位画板。本地查看入口 `/local`。


## 画板预览

页面与画板由浏览器按视口实时绘制，服务端不再渲染缩略图。工作台卡片封面直接取自 Sketch 包内的 `previews/preview.png`（解析时抽出），没有该文件时仍显示占位。备份仍需保留整个 `data/` 目录（账号、设计、字体与解析产物）。
