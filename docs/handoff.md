# 阶段交付记录 · 2026-11-02

本阶段：团队设计查看与 AI 交付预览版。

## 启动与验证

Node.js 24；首次执行 `npm install`、`npx playwright install chromium --only-shell`，随后 `npm run dev`。前端 5173，后端 5174。完整检查为 `npm run build` 和 `npm test`。部署与数据备份参考 local-deployment.md。

## 当前能力

- 根网址按登录状态进入登录页或工作台；本地文件入口在新标签页打开，免登录。
- 团队、项目、上传、成员邀请与权限、固定稿件、重复文件复用。
- 页面默认总览，服务端缩略图、视口裁剪；双击画板进入检查，浏览器后退返回总览并恢复视角。
- 页面与图层分区，搜索只匹配一级画板/容器名称；点击名称不展开，箭头展开。
- 直选内部图层、空格拖动、Alt 测距、文字与样式检查。
- 选定画板或容器导出 AI ZIP，可勾选 SVG 预览、结构 JSON、资源、说明和 HTML 参考。

## 产品约定

保持简洁，避免后台管理风格与常驻技术提示；使用图标库。品牌为 GeekDesign，紫色 GK 小鱼眼睛标识。工作台只保留一个入口。面板动画暂不启用。字体调整不改变设计稿本身。

## 已知限制与下一步

- 字体库尚未实现，当前可临时加载本机字体；缺失字体和复杂效果可能影响还原。
- 项目文件卡片仍使用通用封面。
- AI 预览为 SVG，HTML 是静态视觉参考；未打包字体，局部导出的父级蒙版和越界效果可能不完整。
- 跨画板多选导出、云存储与更完整的版本能力待后续设计。
- 还原度主要围绕现有大型 Sketch 验证，需收集更多真实文件反馈。

## 换电脑

Git 仅同步代码和说明。`data/`、Sketch 原文件、字体、`.env` 均不入库。公司可重新注册并上传；保留数据需停止服务后完整备份 data，单独迁移。不要把设计文件、账号数据或密钥提交到仓库。
