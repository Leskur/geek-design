# 页面操作与单画板视图

打开文件或切换页面默认进入页面视图，按 Sketch 原始坐标展示画板。带 `artboard` 查询参数的固定链接直接进入单画板视图。

## 页面内操作

- 单击内部元素直接选择图层，右侧显示开发检查面板；Shift + 单击选择父级。
- 单击画板名称选择画板；双击画板只放大定位，不切换视图。
- 右键画板选择「打开单画板」，或使用选中画板下方的同名入口，进入聚焦视图。
- 左侧统一展示画板 → 分组 → 图层。点击画板或图层在当前视图定位，不自动切换到单画板。
- 搜索当前只匹配一级画板名称，不搜索内部文字和图层；匹配项在页面中突出显示。
- 选中元素后按住 Alt 悬停其他元素显示距离；页面模式支持跨画板比较边缘距离。

默认工具将点击选择和拖动平移合并。移动超过 4 个屏幕像素才开始平移，松手不触发选择；轻微抖动仍算点击。空格 + 拖动、中键拖动继续可用。空白处显示可拖动游标，画板内使用白色主体、黑色细边和轻微阴影的箭头。

## 缩放与工具栏

| 操作 | 行为 |
| --- | --- |
| 滚轮 | 平移；Shift + 滚轮可横向平移 |
| Ctrl / Command + 滚轮 | 以指针位置为中心缩放 |
| Ctrl / Command + 加号、减号 | 以可见区域中心缩放 |
| Ctrl / Command + 0 | 适合全部；单画板模式下适合当前画板 |
| Ctrl / Command + 1 | 100% |

顶栏中间保留默认工具，缩放百分比菜单位于最右侧，可选择倍率或适合视图。不再常驻显示加减、适宽和缩放到选中按钮。工具按钮不显示边框，缩放百分比显示整数。

单画板返回页面后，恢复进入前的视角与选中项。视角按页面保存在当前文件会话中，刷新或重新打开文件后不保留。

## 分级渲染

页面只渲染视口及附近的画板。其他画板用缩略图，选中和停留操作的画板最多展开两个完整场景。悬停只更新高亮与测距，图层绘制和坐标索引复用缓存，拖动缩放不再反复重建所有画板。

- 缩放低于 15%，或画板屏幕最大边不超过 96px 时，优先使用低采样预览。
- 中间倍率使用较清晰缩略图。
- 缩放至少 50% 且屏幕最大边超过 160px 时，操作中的画板显示完整图层。
- 远离优先预览范围的画板也使用低采样版本；小倍率下仍支持几何选层，选中框和测距独立绘制。

团队模式使用服务端生成的 SVG 与 WebP，本地模式在浏览器串行生成 PNG。低采样最大尺寸为 192 × 768，普通本地预览最大尺寸为 256 × 1024，均不强行放大小画板。预览暂停于移动期间，停下后继续，可见选中项优先。场景缓存最多 20 个，浏览器本地缩略图缓存最多 48 个。

## 服务端预览

服务端由独立 Node.js 子进程生成 SVG 与低采样 WebP，使用 Sharp 转换位图，不依赖 Chromium。当前产物目录为 `artifacts/<key>/thumbnails/thumb-svg-4/`。同一文件共享预览，读取时仍验证项目权限；生成后原子发布，重启补齐缺失产物，版本升级自动重新生成。

页面工具栏不提供「重试预览」按钮；任务进度可通过 `/api/revisions/:id/thumbnails` 查询。预览使用当前渲染器支持的效果，远景文字为简化排版，现有服务端缩略图不会使用团队字体库。单画板组件展开仍有十万图层的资源保护上限；页面字体扫描不再为统计字体而展开整页场景。
