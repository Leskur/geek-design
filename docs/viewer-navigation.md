# 页面总览与统一导航

打开文件或切换页面默认进入总览，按 Sketch 原始坐标展示画板；带 `artboard` 的固定链接继续直接进入细节查看。

- 单击画板选中，双击或点击「查看详情」进入图层检查。
- 左侧统一展示画板 → 分组 → 图层。点击画板定位，点击内部图层进入检查并定位选中元素。
- 搜索支持画板名、图层名、文字和组件覆盖内容，总览同步突出匹配画板。
- 支持空格、手形工具或中键拖动，滚轮平移、Ctrl / Command + 滚轮缩放，以及「适合全部」。
- 当前文件会话内按页面保存总览视角，返回总览时恢复；刷新或重新打开文件后不保留。

总览使用 PNG 图片，进入详情才使用完整 SVG。首次预览由浏览器串行生成，停下拖动后补齐，选中画板优先；本地文件可见区域最多同时生成 16 张预览；团队模式不再限制 16 张，会加载可见区域及周边 240px 内的全部服务器图片，缓存最多 48 张图片和 20 个展开场景。图片包含当前渲染器支持的内容，与 Sketch 原生渲染仍可能存在差异。超大画板的首次生成仍有计算开销。

团队稿件在解析就绪后由独立 Chromium 子进程预生成缩略图，保存在解析产物的 thumbnails/thumb-1/ 下；同一文件共用图片，每个固定稿件的读取仍验证项目权限。已有稿件启动后自动补生成，重启从已写入的 PNG 继续。成员浏览器直接按需请求服务器图片，不再重复生成。预览失败不影响完整稿件查看；有上传权限的成员可在总览工具栏点击「重试预览」。服务端任务进度通过 /api/revisions/:id/thumbnails 查询。
