# 页面操作

打开文件或切换页面后，按 Sketch 原始坐标展示画板。带 `artboard` 查询参数的链接直接进入单画板。

- 单击选图层，右侧出检查面板；Shift + 单击选父级。单击画板名称选画板；双击画板只放大，不切换视图。
- 右键画板「打开单画板」，或用选中画板下方的入口进入聚焦视图。
- 左侧是画板 → 分组 → 图层。搜索只匹配一级画板名称。
- 选中后按住 Alt 悬停其他元素显示距离，页面模式可跨画板比较。
- 默认工具把点击选择和拖动平移合在一起：移动超过 4 像素才平移，松手不触发选择。空格 / 中键拖动仍可用。

| 操作 | 行为 |
| --- | --- |
| 滚轮 | 平移；Shift + 滚轮横向平移 |
| Ctrl / Command + 滚轮 | 以指针为中心缩放 |
| Ctrl / Command + 加号、减号 | 以可见区域中心缩放 |
| Ctrl / Command + 0 | 适合全部；单画板模式适合当前画板 |
| Ctrl / Command + 1 | 100% |

缩放百分比在顶栏最右侧。单画板返回页面后，恢复进入前的视角和选中项；刷新后不保留。
